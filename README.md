# Kitabu

## Overview

Kitabu is an Android application developed using Kotlin in Android Studio for higher education institution libraries, so what it does
is that it allows students to search, browse the textbooks on catalog, reserve as well as updating the reservation in realtime and manage textbooks.


## Features

* Students browse Textbooks on catalog
* Search and view added books
* Reserve Textbooks
* Approve or Cancel the reservation
* View Reservations
* Admin Login
* Admin Book Management(Adding the textbooks)
* Book Availability Management in Realtime(pending, Borrowed)

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Room Database
* SQLite
* ViewModel
* Navigation

## How to Run

1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Run the application on an Android emulator or Android device.

## Project Structure

The project includes:

* Book catalogue
* Book reservations
* Admin management
* Local database storage
